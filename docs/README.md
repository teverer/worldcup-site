## 推荐阅读顺序

1. **项目说明** —— 先把项目在自己电脑上跑起来
2. **团队分工方案** —— 认领模块与文档
3. **编码规范 + Git 规则 + 界面设计规范** —— 写代码前
4. **需求 + 设计 + 数据来源** —— 查功能、字段、统计口径
5. **项目上下文** —— 接手排错或需要了解"为什么这样做"时

## 两个必须记住的约定

1. **比赛表叫 `game`,不叫 `match`**。`match` 是 PHP 8 的保留关键字,按它生成的模型类无法编译。
2. **留言和点赞需要登录**。前台注册/登录使用 Yii2 advanced 模板自带的那套。
