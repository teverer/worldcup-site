## 推荐阅读顺序

1. **项目说明** —— 先让项目在自己电脑上跑起来
2. **团队分工方案** —— 认领一个代码模块和搭配的文档
3. **编码规范 + Git 协作规则** —— 知道代码怎么命名、怎么提交、怎么合并
4. **需求 + 设计文档** —— 写代码时查具体功能、字段和统计口径

## 两个必须记住的约定

1. **比赛表叫 `game`,不叫 `match`**。`match` 是 PHP 8 的保留关键字,按它生成的模型类 `class Match` 无法编译。
2. **留言和点赞需要登录**。前台注册/登录使用 Yii2 advanced 模板自带的那套。

## 文档的最终形态

现在都是 Markdown(方便协作和版本管理)。作业提交时需要导出为 PDF,命名格式:

```
队名_文档名(学号1_学号2_学号3).pdf
例:国足世界杯夺冠队_需求文档(学号1_学号2_学号3).pdf
```

导出后放到 `data/team/` 目录,并在网站下载页提供链接。
