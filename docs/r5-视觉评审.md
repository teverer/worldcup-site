# R5 视觉评审：浅色数据页的“档案登记册”美术层

> 会话：win-WorldCup-5 · 2026-11-24
> 范围：前台浅色数据页与壳层的**颜色 / 边框 / 背景 / 焦点 / 悬停**；不碰字号、行高、间距、布局、视图结构、图表逻辑。
> 交付：`frontend/web/css/art-r5.css`（最后加载的覆盖层）+ 本文档。
> 预览：`runtime/qa/r5/`（本机截图，已 gitignore）；注入路由预览法见文末。

## 1. 一句话方向

浅色页不是“米色后台”，而是一份**赛后档案登记册**：中性档案纸、深绿墨、铜色只做结构标记、细横线组织表格；右上角一枚极淡的球场中圈水印，把根页的夜场身份带进纸面。

这个方向针对用户的原话：“根页配色还可以，其他页面配色 / 效果太丑”。根页的夜场不动；改的是纸面数据页的“印刷品感”，不是再换一套色板。

## 2. 改了什么

### 2.1 纸与墨

- 纸从偏黄的奶油色收成更中性的档案纸；边框从“米色线”换成墨调细线，避免整页糊成一片米色。
- 背景加三层极淡底纹：右上球场中圈、左下铜色暖光、纸面颗粒（沿用 v2 的颗粒层）。
- 桌面端在容器左侧加一条“装订线”渐变，和右侧中圈形成版面边距；窄屏不显示。

### 2.2 壳层

- 页头下沿压一条极细铜线；页脚从浅纸改为深墨 + 铜色压边。上下两块深色把纸面“夹住”，短页面不再头重脚轻。
- 面包屑、页脚链接、焦点环统一到墨 / 铜 / 绿三色；焦点环换成铜色，键盘用户更容易看见。

### 2.3 组件语法：从“盒子”改成“登记册”

- 检索区（球队 / 球员 / 比赛 / 资讯）：去掉四边框和白卡底，改为上墨线 + 下细线的抬头行。
- 表格：表头上墨线、行间细线、行悬停淡绿；表尾补一条收口线；数字列 `tabular-nums`。
- 球队目录：83 个 bordered 小卡改成印刷索引行；悬停时左侧亮起铜线。
- 年份 / 小组筛选：从一排盒子改成页签（细底线 + 当前项铜色下划线）。
- 榜单 / 资讯 / 留言行：悬停用 3px 铜色起笔，而不是整块变色。
- 关于页四格数字：从四个白盒改成一条深墨记分牌，铜色压顶；这是整页最重的一块，和“11 / 83 / 708 / 1832”的分量相称。
- 图表卡：上墨线 + 纸面底；小组切换按钮改成页签；图表视觉本身仍归图表会话。
- 登录 / 注册：去掉浮起白卡，改成一张居左登记表（上墨线、下细线）。
- 空态 / 错误页：去掉虚线空框（总纲 §17.5 明令禁止），改为一条横线 + 一句安静说明。

### 2.4 深色身份头

- 球队 / 球员身份头、届次 hero、比赛比分牌底部各压一条铜线，与夜场舞台接上；不额外加光效。
- 上 / 下一届卡片加铜色顶线，像档案里的两张索引卡。

### 2.5 后台工作间

- 工作台六个数字卡加铜色顶线，从白盒变成登记卡；待补 / 快速新增面板补一条墨线。
- CRUD 列表去掉表格盒子与通栏边框，改成纸面表格：表头墨线、行间细线、行悬停淡铜。
- “已结束”等状态改成细线标签；“查看 / 编辑 / 删除”从三块实心彩色按钮降成三种细线印章，悬停才填色。
- 当前导轨项加铜色左线；分页、提示条、表单焦点与前台同一语法。

## 4. 查出的问题与归属

> 本会话只修颜色层能修的；下面按“谁的范围”标注，已同步给对应会话。

1. **字体切页跳变（-4，处理中）**：得意黑 1.1MB + `font-display: swap` + 静态资源无缓存头。已见子集化（192KB）、preload、`font-display: optional`。仍建议部署侧给 `/fonts/*.woff2` 长缓存 + `immutable`；`yii serve` 不返回缓存头是开发服务器行为。
2. **届次页 390 的 hero 四格事实被裁切（-4，布局）**：`scrollWidth` 不溢出，但 `.td-hero-facts` 内部超宽被裁；“参赛队 / 进球”标签在 390 只看到后半截。需要移动端重排（例如 2×2 或把“场均进球”并入一行）。
3. **资讯详情 / 全站留言簿的内容列与面包屑起始线不一致（-4，布局）**：内容窄栏居中、面包屑左对齐；两套左轴。已知在改。
4. **球员详情 0 进球时页面过空（-4 / -2，内容与图）**：有数据球员已有“历届进球与助攻”图；0 进球球员只剩一行生涯表。建议补“出场记录 / 所在球队”而不是给 0 数据画空图。
5. **各队进球分布的类别色过近（-2，图表）**：占比语义已修正为固定分母，但前 7 队里 5 个绿色太接近，图例与扇区需要靠文字才能对上。建议在站内色板内拉开明度 / 色相（深绿、铜、石板蓝、青灰、陶土），仍保持“绿 = 数据、金 = 第一”。
6. **导航下划线“超出文字”是错觉（已核）**：实测下划线宽度等于链接宽度；1440 全页缩放造成视觉误判，不是缺陷。
7. **后台美术层（本会话补，-4 结构范围不动）**：`backend/web/css/art-r5.css` 已加，纸面表格 / 铜线状态 / 降噪操作；结构与 GridView 列仍归 -4。两处 layout 的注册行已由本会话临时加入，由 -4 随其提交带上。

## 5. 协作边界

- `art-r5.css` 由 win-WorldCup-5 独占；其他会话不要直接改。需要新样式：在看板写 class 名，或把元素结构 / class 交给本会话。
- 加载顺序必须是：模块 CSS → `theme.css` → `design-v2.css` → `art-r5.css`。前台与后台各一行，已临时加入 `frontend/views/layouts/main.php`、`backend/views/layouts/main.php`，由 -4 提交。
- 本文件只覆盖颜色 / 边框 / 背景 / 焦点 / 悬停；新增字号、间距、栅格、断点请交给 -4。
- 若后续 C 会话回来调整色板，以 C 的令牌为准；本层用变量引用，不写死除水印 / 铜色半透明以外的颜色。

## 7. 本机预览法（不提交）

`runtime/qa/r5/router.php` 是一个仅用于截图的注入路由：把请求交给 `frontend/web/index.php`，在 `</head>` 前插入 `art-r5.css`。启动：

```bash
php -S localhost:8095 -t frontend/web runtime/qa/r5/router.php
```

`runtime/qa/r5/cdp_shot.py` 用 CDP 设置真实 390 / 768 / 1440 宽度并输出 `scrollWidth`，避免 `--window-size` 在 Windows 上的最小宽度误差。
