# 团队分工方案(国足世界杯夺冠队)

> 技术栈:Yii2 advanced + MySQL(MVC)。4 人小队。
> 本文档用于组员**自选**代码模块与文档,剩余部分由队长兜底。

## 一、分工原则

 每人负责 **1 个代码模块 + 对应文档**。每个模块都包含 MVC 三层(Model / View / Controller),满足作业要求「每个组员至少编写 MVC 三层各一个文件」。
## 二、已由队长承担(无需组员认领)

| 任务 | 说明 |
|---|---|
| 编码规范 + 注释头模板 | 统一命名约定、php 文件注释头格式 |
| `install.sql` | 14 张表建表语句|
| Yii2 项目初始化 + db.php | 仓库骨架、frontend/backend 配置、数据库连接 |
| Git 仓库 + Trello 管理 | 建仓库、分支规范、日常合并、看板维护 |
|可负责ppt主讲

## 三、代码模块(4 块,一人认领一块)

| 模块 | 内容 | 主要涉及的表 | 编程强度 |
|---|---|---|---|
| 1 框架与团队主页 | 前后台框架(前台 layout/导航/首页,后台 layout/登录/后台首页)、团队展示(前台展示 + 后台编辑)、作业下载页、全局 CSS | `team_info` `member` `work` | 页面多但简单 |
| 2 球队与球员 | 球队列表/详情 + 后台增删改查、球员列表/详情 + 后台增删改查、可加球员数据等动态图,可操作性大 | `team` `player` | 中偏重 |
| 3 届次与比赛 | 届次管理、参赛队管理、名单管理、比赛管理 + 进球录入(含助攻、乌龙归属)、选加赛事动态图 | `tournament` `tournament_team` `squad` `game` `goal` | 最重 |
| 4 留言与资讯 | 留言(登录后发表/回复/点赞/删除)、资讯(前台展示 + 后台增删改查) | `comment` `comment_like` `news` | 中 |

> `user` 表为公共表,登录(模块①)、留言/点赞(模块④)共用。前台注册/登录直接用 Yii2 advanced 模板自带的那套,不需要从零写。
> 比赛表名为 `game`(不叫 `match`):`match` 是 PHP 8 保留关键字,按它生成的模型类无法编译。

## 四、文档(6 份,与模块搭配认领)

| 文档 | 工作量 | 建议搭配模块 |
|---|---|---|
| 需求文档 | 轻(已有底稿,统稿导出) | 3 |
| 设计文档 | 中(数据库字典 + 模块图 + 流程图) | 2 |
| 实现文档 | 中重(汇总全队 Git 记录 + 代码目录展示) | 4 |
| 用户手册 | 中(截图 + 操作说明) | 4 |
| 部署文档 | 最轻(部署还原步骤 + 一键部署脚本) | 1 |
| 项目展示 PPT | 重(答辩材料,整合全队内容) | 1(其中讲解部分可交给队长) |

> 搭配原则:代码越重 → 文档越轻;代码越轻 → 文档越重,让四人总量均衡。

## 五、认领方式


1. 认领组合:

| 代码模块 | 搭配文档 |
|---|---|
| 3 届次与比赛(最重) | 需求文档 |
| 2 球队与球员(中偏重) | 设计文档 |
| 4 留言与资讯(中) | 用户手册 + 实现文档 |
| 1 框架与团队主页(最轻) | 部署文档 + 项目展示 PPT(讲解可交队长) |

3. 其中ppt制作任务因包含各处的部分内容,以及可能需要与讲解人协调,任务量不好界定,若过多可选将部署文档任务交予模块4留言与资讯。

## 六、动态图归属

- 赛事级:模块3的选择并添加至少2两份动态图(如积分榜、射手榜、进球分布)
- 球员级:模块2可选是否添加动态图(如果某球员数据图、球员数据变化图等等,可选)
