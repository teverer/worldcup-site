## 1. 项目概述与范围

### 1.1 项目背景与目标

首先本站最初是为了对应课程要求的"世界杯"主题,之后我们具体考量了我们的能力和这个网站可能实现的价值后,决定制作一个偏展示而不是具有更多功能性的网站,关于展示什么我们决定是世界杯 1986–2026 这最近40年的一些内容,包括当时的一些照片,一些基本数据和一些可视化展示.另外展示意味着带给人感触,为此我们加上了留言分享的功能好方便访客的情感抒发和增进.

最后我们决定制作这个"展示"与"感触分享"一体的网站.

### 1.2 用户角色与权限

| 角色 | 浏览 | 留言 / 回复 | 点赞 | 后台管理及发布资讯 |
|---|---|---|---|---|
| 访客 | ✓ | ✗ | ✗ | ✗ |
| 登录用户 | ✓ | ✓ | ✓ | ✗ |
| 管理员 | ✓ | ✓ | ✓ | ✓ |

### 1.3 一些暂不实现的功能

- 实时比分直播(我们的网站偏向历史展示而不是实时的)
- 支付 / 电商 / 博彩
- 社交账号登录
- 移动端
- 找回密码

## 2. 功能需求

### 2.1 前台功能

| 功能 | 说明 |
|---|---|
| 首页 / 导航 | 引导访客进入届次详情与各模块 |
| 球队列表 / 详情 | 列表可筛选；详情含资料与球员名单等 |
| 球员列表 / 详情 | 列表可筛选；详情含进球 / 助攻等 |
| 比赛记录 | 列表可筛选；详情含进球时间、球场等 |
| 实体下留言 | 登录后可在球队 / 球员 / 比赛 / 资讯下留言、回复、点赞；同一留言每人只能点赞一次，可取消；留言默认直接发布，管理员可删除 |
| 可视化图表 | 射手榜、各队进球分布、球员星云等，详见 2.3 |
| 团队及个人展示 | 团队介绍与成员姓名 / 学号 / 分工 / 照片 |
| 作业下载 | 团队作业、个人作业下载链接 |

### 2.2 后台功能

| 功能 | 说明 |
|---|---|
| 管理员登录 | 账号密码登录；未登录访问后台跳转登录页 |
| 届次管理 | 届次增删改查；维护年份、东道主、赛制、胜场积分等 |
| 球队管理 | 球队增删改查；维护队名、FIFA 代码、大洲、国旗 / 队徽、简介等 |
| 球员管理 | 球员增删改查；维护姓名、中文名、国籍、位置、照片等 |
| 参赛队管理 | 给某届录入参赛队；设置小组等 |
| 名单管理 | 给某届某队录入球员名单；设置球衣号与位置 |
| 比赛管理 | 比赛增删改查；录入比分、阶段、时间、球场；可进入进球录入 |
| 留言管理 | 按内容 / 用户 / 目标 / 状态筛选；删除后前台不再显示 |
| 资讯 / 公告发布 | 资讯增删改查；维护标题、作者、正文、封面与发布状态 |
| 团队信息编辑 | 维护团队介绍、成员信息与作业文件 |

### 2.3 可视化图表

| 图表 | 说明 |
|---|---|
| 本届射手榜 Top 10 | 按球员统计本届进球，排除乌龙球与点球大战进球，取前 10 名 |
| 本届各队进球分布 | 按球队统计本届进球占比，并给出全届总进球；排除点球大战，乌龙球计入受益队 |
| 球员星云 | 四十年进球球员（进球 ≥2）的点阵：横轴为生涯进球，纵轴为参赛届数或生涯助攻，可按届播放，颜色区分大洲 |
| 四强版图 | 逐届列出四强球队，并按大洲显示四强构成 |
| 球队的世界杯轨迹 | 按届显示球队的最终阶段 / 名次，夺冠届标出金点；只画已录入比赛的届次 |
| 球员的历届进球与助攻 | 按届统计球员的进球与助攻，无记录的届次计 0 |
| 比赛的比分走势 | 按进球分钟累计双方比分；不含点球大战，常规进球不足 2 个时不画 |

小组积分榜以表格呈现，归入届次页的「小组赛」，不计入图表。乌龙球指进球的最后一次触球球员是本队球员而不是对手的进球.

### 2.4 质量要求

- 安全：密码不明文存储；后台功能需管理员登录；用户输入不得被当作脚本或 SQL 执行。

## 3. 数据来源

### 3.1 数据规模

| 项目 | 数量 |
|---|---|
| 届次 | 11 届 |
| 比赛 | 708 场 |
| 进球 | 2045 个 |
| 球队 | 83 支 |
| 参赛队记录 | 344 条 |
| 名单记录 | 6743 条 |
| 球员 | 5086 名 |

### 3.2 比赛数据来源

- **1986–2022（604 场）**：来自 [openfootball/worldcup](https://github.com/openfootball/worldcup)，使用 `more/<年份>_full.txt` 的比赛与进球、`more/<年份>_squads.txt` 的名单 / 球衣号 / 位置 / 生日；用 [martj42/international_results](https://github.com/martj42/international_results)逐场校验比分与日期，并补充助攻。604 场的日期、球队、120 分钟比分与第二来源一致。
- **2026（104 场）**：比赛来自 openfootball/worldcup 的 `2026--canada-usa-mexico/` 目录，含 72 场小组赛与 32 场淘汰赛；名单来自同仓库 `more/2026_squads.txt`；助攻来自 martj42/international_results 的 `goalscorers.csv`，补充 222 条。决赛、半决赛、三四名决赛与 FIFA 官网、Wikipedia、Flashscore 等公开报道核对一致。
- **文件位置**：`data/real_worldcup_data.sql`（1986–2022）、`data/real_worldcup_2026.sql`（2026 比赛）、`data/real_worldcup_2026_extras.sql`（2026 全量名单与助攻）。

### 3.3 球员中文名来源

`player.name` 保留原名，`player.name_zh` 存中文名；前台默认显示原名，可切换中文名，搜索同时匹配两者。

- **覆盖**：5086 名球员全部有中文名。
- **来源**：原有译名 4282 条。补充部分 3220 条来自 Wikidata / 中文维基条目名，93 条来自 Bing 词典全名，855 条为 AI 音译补充；2026 新增 810 条中 521 条来自中文维基 2026 参赛球员名单，21 条来自 Wikidata 校验命中，268 条为 AI 音译补充。
- **精度**：Wikidata / 中文维基优先；冷门球员的 AI 音译只保证“可读的中文名”，不保证大陆媒体统一译法。
- **文件位置**：`data/player_name_zh.sql`、`data/player_name_zh_2026.sql`；逐人来源见 `data/player_name_zh_map.tsv` 与 `data/player_name_zh_2026_map.tsv`。
