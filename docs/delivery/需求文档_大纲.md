## 1. 项目概述与范围

### 1.1 项目背景与目标

首先本站最初是为了对应课程要求的"世界杯"主题,之后我们具体考量了我们的能力和这个网站可能实现的价值后,决定制作一个偏展示而不是具有更多功能性的网站,关于展示什么我们决定是世界杯 1986–2026 这最近40年的一些内容,包括当时的一些照片,一些基本数据和一些可视化展示.另外展示意味着带给人感触,为此我们加上了留言分享的功能好方便访客的情感抒发和增进.

最后我们决定制作这个"展示"与"感触分享"一体的网站.

### 1.2 用户角色与权限

| 角色 | 浏览 | 留言 / 回复 | 点赞 | 后台管理及发布资讯 |
|---|---|---|---|---|
| 访客 | ✓ | ✗ | ✗ | ✗ |
| 登录用户 | ✓ | ✓ | ✓ | ✗ |
| 管理员 | ✓ | ✓ | ✓ | ✓ |

### 1.3 一些暂不实现的功能

- 实时比分直播(我们的网站偏向历史展示而不是实时的)
- 支付 / 电商 / 博彩
- 社交账号登录
- 移动端
- 找回密码

## 3. 数据来源

### 3.1 数据规模

| 项目 | 数量 |
|---|---|
| 届次 | 11 届（1986–2026） |
| 比赛 | 708 场 |
| 进球 | 2045 个 |
| 球队 | 83 支 |
| 参赛队记录 | 344 条 |
| 名单记录 | 6743 条 |
| 球员 | 5086 名 |

### 3.2 比赛数据来源

- **1986–2022（604 场）**：来自 [openfootball/worldcup](https://github.com/openfootball/worldcup)（CC0-1.0），使用 `more/<年份>_full.txt` 的比赛与进球、`more/<年份>_squads.txt` 的名单 / 球衣号 / 位置 / 生日；用 [martj42/international_results](https://github.com/martj42/international_results)（CC0-1.0）逐场校验比分与日期，并补充助攻。604 场的日期、球队、120 分钟比分与第二来源一致。
- **2026（104 场）**：比赛来自 openfootball/worldcup 的 `2026--canada-usa-mexico/` 目录，含 72 场小组赛与 32 场淘汰赛；名单来自同仓库 `more/2026_squads.txt`（48 队 × 26 人，含球衣号、位置、生日）；助攻来自 martj42/international_results 的 `goalscorers.csv`，补充 222 条。决赛、半决赛、三四名决赛与 FIFA 官网、Wikipedia、Flashscore 等公开报道核对一致。
- **文件位置**：`data/real_worldcup_data.sql`（1986–2022）、`data/real_worldcup_2026.sql`（2026 比赛）、`data/real_worldcup_2026_extras.sql`（2026 全量名单与助攻）。

### 3.3 球员中文名来源

`player.name` 保留原始拉丁名，`player.name_zh` 存中文名；前台默认显示原名，可切换中文名，搜索同时匹配两者。

- **覆盖**：5086 名球员全部有中文名。其中 4276 条为原有译名，810 条为 2026 全量名单新增球员的中文名（中文维基 521 条 + Wikidata 21 条 + AI 音译 268 条）。
- **来源**：原有译名 4282 条（112 条人工定稿 + 4170 条补充；其中 6 条为 2026 进球者重复建档，合并后 4276 条）。补充部分 3220 条来自 Wikidata / 中文维基条目名，93 条来自 Bing 词典全名，855 条为 AI 音译兜底；2026 新增 810 条中 521 条来自中文维基 2026 参赛球员名单，21 条来自 Wikidata 校验命中，268 条为 AI 音译兜底。
- **精度**：Wikidata / 中文维基优先；冷门球员的 AI 音译只保证“可读的中文名”，不保证大陆媒体统一译法。
- **文件位置**：`data/player_name_zh.sql`、`data/player_name_zh_2026.sql`；逐人来源见 `data/player_name_zh_map.tsv` 与 `data/player_name_zh_2026_map.tsv`。

### 3.4 统计口径

- 2026 届点球大战只记录总比分，不逐轮记录主罚者；比赛详情展示总比分。
- 进球分钟按来源的“基础分钟”记录（如 45+3' 记为 45）。
- 历史国家身份按当时国名独立建档（西德、苏联、捷克斯洛伐克、南斯拉夫不与现代国家合并）。
- 积分榜、射手榜、各队进球分布的具体口径见 2.3；字段、类型、索引、约束见《设计文档》，本文不重复。
