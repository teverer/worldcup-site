## 一、访问网站

前台地址：

```text
http://localhost:8080
```

后台地址：

```text
http://localhost:8081
```

## 二、注册与登录

1. 在顶部导航点击“Signup”。
2. 输入登录名、昵称和至少 6 位密码。
3. 注册成功后返回首页。
4. 点击“Login”，输入用户名和密码。
5. 登录后导航显示当前用户名和“Logout”按钮。

游客可以浏览球队、球员和资讯，但不能发表留言或点赞。

## 三、浏览资讯

1. 在前台导航点击“资讯”。
2. 页面展示已发布资讯，草稿不会出现。
3. 在搜索框输入标题或作者关键词。
4. 点击“搜索”进行筛选。
5. 点击资讯卡片或“阅读全文”进入详情。

资讯详情只展示状态为“已发布”的内容。

## 四、留言与回复

### 发表留言

1. 登录后进入球队、球员或资讯详情页。
2. 滚动到页面底部留言区。
3. 输入留言内容。
4. 点击“发表留言”。
5. 页面返回详情页并显示新留言。

### 回复留言

1. 点击目标留言下方的“回复”。
2. 输入回复内容。
3. 点击“发表回复”。
4. 回复显示在父留言下方。

回复必须和父留言属于同一个页面，不能跨实体回复。

### 点赞

1. 登录后点击留言下方的“赞”。
2. 点赞数量增加。
3. 同一用户对同一条留言只能点赞一次。

### 删除留言

- 普通用户可以删除自己发表的留言。
- 管理员可以删除任意留言。
- 删除父留言后，其全部回复一并隐藏。

## 五、后台资讯管理

1. 使用管理员账号登录后台。
2. 点击导航“资讯管理”。
3. 使用搜索框和状态筛选查找资讯。
4. 点击“新增资讯”发布新内容。
5. 填写标题、作者、正文并选择状态。
6. 可上传 JPG、PNG、WebP 或 GIF 封面，最大 5 MB。
7. 选择“已发布”后保存，资讯立即在前台可见。
8. 编辑资讯时可上传新封面替换旧封面。
9. 点击删除后确认，资讯及其留言一并删除。

正文支持基础 HTML，系统会自动移除脚本和危险标签。

## 六、后台留言管理

1. 使用管理员账号登录后台。
2. 点击导航“留言管理”。
3. 可按留言内容、用户名、留言目标或状态筛选。
4. 点击“删除”并确认。
5. 已删除留言保留管理记录，但不在前台显示。

## 七、常见问题

### 登录后仍看不到留言输入框

确认浏览器允许 Cookie，并刷新页面。

### 上传封面失败

检查文件是否小于 5 MB，格式是否为 JPG、PNG、WebP 或 GIF，并确认 `frontend/web/uploads/news/` 可写。

### 页面提示留言目标不存在

返回目标详情页重新进入，避免使用已删除或错误的目标编号。

### 草稿资讯在前台打不开

这是正常行为。请在后台把状态改为“已发布”。
