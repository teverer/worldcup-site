## 一、项目概述

本项目采用 Yii2 advanced、PHP 和 MySQL，实现世界杯数据展示、比赛记录、球队与球员资料、资讯发布及社区留言。项目采用前后台分离结构，公共模型和业务组件放在 `common/`。

## 二、技术架构

```text
frontend/  前台页面和用户交互
backend/   后台管理
common/    公共模型、组件和校验
data/      SQL 脚本与演示数据
tests/     数据库与 HTTP 验收脚本
docs/      需求和设计文档
```

Yii2 MVC 调用链：

```text
浏览器请求
  -> Controller 参数与权限检查
  -> Model 数据校验和持久化
  -> View 输出页面
  -> Active Record / Query 访问 MySQL
```

## 三、模块④实现内容

### 3.1 数据模型

| 类 | 职责 |
|---|---|
| `News` | 资讯状态、发布时间、HTML 清理、封面上传属性 |
| `NewsSearch` | 前台发布查询和后台筛选 |
| `Comment` | 多态留言、回复树、软删除、点赞状态 |
| `CommentLike` | 用户点赞关系与重复校验 |
| `CommentTarget` | 五类留言目标的存在性、标签和路由映射 |

### 3.2 前台实现

- 资讯列表、搜索、分页和详情
- 草稿隔离
- 可复用 `CommentSection` 组件
- 登录后发表、回复、点赞和删除
- 与球队、球员和资讯详情页集成

### 3.3 后台实现

- 资讯增删改查
- 草稿/发布状态切换
- 多部分表单封面上传
- 封面替换和文件清理
- 留言列表、搜索、目标和状态筛选
- 管理员软删除留言及回复树

## 四、关键业务流程

### 资讯发布

```text
管理员填写资讯
  -> 字段及上传文件校验
  -> HTMLPurifier 清理正文
  -> 保存封面并获取随机相对路径
  -> 保存资讯
  -> 发布时自动设置 publish_time
  -> 前台只查询已发布记录
```

### 留言发布

```text
用户提交留言
  -> 登录和 CSRF 检查
  -> 目标类型及目标记录校验
  -> 回复时校验父留言目标一致
  -> user_id 取自登录身份
  -> 保存留言并跳回目标详情页
```

### 删除留言

```text
作者或管理员发起删除
  -> BFS 收集全部后代回复
  -> 事务内设置 status=1
  -> 前台有效查询排除整棵回复树
```

## 五、安全措施

- POST + Yii2 CSRF
- 登录与角色鉴权
- 目标类型固定白名单
- 父留言跨实体和循环关系校验
- 留言输出转义
- 资讯 HTMLPurifier
- 上传扩展名、MIME 和大小校验
- 服务端随机文件名
- 点赞数据库唯一索引
- 普通用户与管理员删除权限隔离
