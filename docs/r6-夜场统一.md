# R6 · 全站夜场统一

> 2026-11-24 · win-WorldCup-5
> 触发：用户反馈“根页之外的其他页面和根页色调风格差太大”“颜色还是有点丑”“字体和组件小、拥挤、不大气”；检查环境为笔记本 1280 / 1366 / 1440，移动端只做不溢出兜底。

## 1. 判断

R5 的“夜场入口 + 暖纸数据页”是两套材料：根页是深色球场，数据页是米色报告。局部看都成立，放在同一个站里就是两个产品。用户要的不是再调米色，而是**同一间球场**。

R6 的做法：**整个前台回到根页的夜色**。根页仍是“入口”，数据页是“看台 / 记分板 / 档案灯箱”；区别靠版式与信息密度，不靠换色板。

## 2. 视觉系统

- **背景**：所有前台页启用与根页同一套 `atmo`（极光、点阵、透视球场线），降低强度，避免干扰数据。
- **表面**：深绿黑 `#050A0C` 页面、`#0A1512` 面板；不再使用米色纸面。
- **文字**：暖白 `#F4F2EC`；次级 `#CFD8D2`；辅助 `#A6B7B0`（深底对比 ≥ 4.5:1）。
- **动作**：青绿 `#7FDDB8` / 深绿按钮 `#0E5138`；**成就**：金 `#E0B457` 只给冠军、第一名、当前项、关键分隔。
- **线**：`rgba(244,242,236,.14)` 细线；表头 2px 金线；卡片靠细线与留白分层，不加白卡阴影。
- **保留的差异**：后台仍是“工作间”（石墨导轨 + 暖纸工作区），和前台明确分房；根页仍是唯一的入场动画。

## 3. 改了什么

- 前台：页头/页脚/面包屑、索引页、详情页、检索面板、表格、目录行、页签、读数带、图表容器、留言簿、登录/注册、空态/错误页，全部换成夜场表面。
- 表格：表头金线、行间细线、行悬停青绿；数字列 `tabular-nums`；不再有米色边框。
- 检索：深色面板 + 金色抬头线；输入框黑底、青绿焦点。
- 卡片 / 图表：深色表面 + 金色顶线；球员页图表与生涯表同一条纸面语法。
- 页脚：深墨 + 金色顶线，所有前台页一致；不再出现浅色页脚突然截断。
- 空态 / 错误：去虚线框，保留一句安静说明。
- 深色身份头：球队/球员/届次/比赛比分牌统一压金线，按钮文字改为深色，避免白底白字。
- **R6.1 桌面字号层**：1280 以上 body 17、正文 17.5、h1 56、区块 h2 30、表格 16、导航/按钮 15；只改字号与行高，不动间距、栅格与断点。390 维持原样。
- **R6.2 主角数字**：比赛索引比分 40、年份 32；关于页四格数字 44。金色收敛为成就色（冠军/第一/当前项/页脚压边），结构线改青绿与银白，避免“金色线框”。
- **首页收场与页脚**：`.wall-coda` 加金顶线 + 深绿面板，作为“最后一页档案”；首页页脚与全站统一为深墨 + 金线。结构、单列留言列表与右侧链接删减归 -4。

## 4. 文件

| 文件 | 作用 |
|---|---|
| `frontend/web/css/art-r6.css` | 夜场统一层：令牌、背景、表面、文字、表格、卡片、页脚、焦点；含 R6.1 桌面字号层 |
| `frontend/views/layouts/main.php` | 在 `art-r5.css` 之后注册 `art-r6.css`（1 行） |
| `frontend/web/css/art-r5.css` | 保留为浅色基础层；被 R6 覆盖，便于回退 |

**回退**：移除 `art-r6.css` 注册行即回到 R5 浅色版；R5 文件未删。

## 7. 参考与取舍

- 根页（本站）：夜场、极光、巨大 Saira 年份、金色冠军——R6 直接把这一套语言扩展到数据页。
- themewagon `soccer/matches`：大图 hero、巨大标题、一屏少量卡片、强留白。可取的是**尺度与留白**；本站没有版权图片，不伪造摄影，用极光/球场线与大数字代替。
- 顶级体育数据站（FotMob / Sofascore / UEFA / ESPN 深色模式）的共性：深底、白字、单一强调色、表格行高充足、图表与列表共用一套表面。R6 采用同一逻辑，但保留“档案 / 记分牌”的金色语义。
