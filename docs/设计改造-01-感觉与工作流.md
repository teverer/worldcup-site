## 1. 用户要的感觉（最高优先级）

修正:这里的颜色方案不一定必要遵循,这里关键是给人的感觉为主要的届次展示要有"紧张、刺激、野性、竞技"感觉但不同的组件模块和页面颜色不要求都这样,而是要张弛有度,设计合理,颜色不一定要确定按照下面的来
- 关键词：**夜场、深蓝 / 夜蓝黑、球场绿、红、紧张、刺激、野性、竞技、张弛有度**。
- 金色：只给冠军 / 纪录 / 奖杯，表现“辉煌”；不要到处用。
- 平淡处：用冷纸 / 灰 / 留白让读者缓和；不要整站一直燃。
- 不是：八卦站、榜单站、数据后台、模板站、直播站。
- 记忆是感觉的副产品：先让人有感觉，再记住一个比分 / 冠军 / 夜晚。
- 反例：四个瞬间 / 最大比分差 / 花絮清单 / 英文 eyebrow / 满屏白卡 / 圆角卡 + 阴影 / 渐变占位图 / 每个链接加箭头 / 大卡片表示一个国家 / PAR、FRA 代码。
- 参考：根页 `frontend/views/site/index.php` + `frontend/web/css/root-wall.css` 是上述这套颜色方案的“感觉”的基准；

## 2. 好页面的标准

- 第一眼有想要的感觉，不是后台；

- 中文名可读；
- 层次：我在哪 / 这里有什么 / 下一步点哪；每页一个主操作；不留死路。
- 结构:结构清晰,主次要模块清楚区分,组件不要多冗余,布局要美观合理,看起来结构明了(布局的合理性可以优先通过与网络上的优秀例子来比对来判断),组件大小要合理
- 与根页并排看，像同一个站；不是“另一个模板”。

## 3. 上一轮的教训

- 只按页面规格机械堆模块，没有抓住“感觉”；结果像 CMS / 后台。
- 保留了旧的横向树 / 四个瞬间 / 代码 / 徽章等被否决的元素。
- 不要让一个比喻变成规格：“看台”本身没错，但把讨论区做成深绿大盒子 + 白卡 + 登录条，就变成了第三方插件。先问这一块要解决什么（留下记忆 / 找到第一条留言），再决定它长什么样。
- 评论区要为“第一条留言”设计，而不是为“海量评论”设计：空态、输入提示、登录门槛都是主设计，不是补丁。
