# 数据来源说明

> 本文件记录网站中比赛数据的来源、覆盖范围与统计口径,供实现文档和答辩引用。
> 更新日期:2026-11-28

## 一、数据规模

| 项目 | 数量 |
|---|---|
| 届次 | 11 届(1986–2026) |
| 比赛 | 708 场 |
| 进球 | 2045 个 |
| 球队 | 83 支 |
| 参赛队记录 | 344 条 |
| 名单记录 | 6743 条 |
| 球员 | 5086 名 |

## 二、数据来源

### 1. 1986–2022(604 场)

- **openfootball/worldcup** — <https://github.com/openfootball/worldcup>
  - 许可:CC0-1.0(公共领域)
  - 使用文件:`more/<年份>_full.txt`(比赛与进球)、`more/<年份>_squads.txt`(名单、球衣号、位置、生日)
- **martj42/international_results** — <https://github.com/martj42/international_results>
  - 许可:CC0-1.0
  - 用途:`results.csv` 逐场校验比分日期,`goalscorers.csv` 校验进球并补充助攻

**校验结果**:604/604 场的日期、球队、120 分钟比分与第二来源完全一致;1524 个进球的每场数量一致;点球/乌龙标记差异为 0。

### 2. 2026(104 场)

- **openfootball/worldcup** 的 `2026--canada-usa-mexico/` 目录
  - 72 场小组赛(A–L 12 组)+ 32 场淘汰赛
  - 含日期、阶段、比分、加时、点球大战总比分、进球者与分钟、点球/乌龙标记、场地
- **openfootball/worldcup** 的 `more/2026_squads.txt`
  - 48 队 × 26 人全量名单,含球衣号、位置、生日
- **martj42/international_results** 的 `goalscorers.csv`
  - 2026 世界杯进球助攻,补充 222 条
- 交叉验证:与 FIFA 官网、Wikipedia、Flashscore 等公开报道核对决赛、半决赛、三四名决赛,结果一致

## 三、统计口径

| 统计项 | 口径 |
|---|---|
| 积分榜 | 仅统计 `stage='小组赛'` 且 `status=2` 的比赛;胜场积分取 `tournament.win_points`(1986/1990 为 2 分,其余 3 分) |
| 射手榜 | 排除乌龙球(`is_own_goal=1`)与点球大战进球(`is_shootout=1`) |
| 各队进球分布 | 按 `goal.team_id` 统计,乌龙球已归入受益方;排除点球大战进球 |
| 总进球数 | 排除点球大战进球,包含乌龙球 |

> 2026 届点球大战只记录总比分,不逐轮记录主罚者;比赛详情展示总比分。
> 进球分钟按来源的“基础分钟”记录(如 45+3' 记为 45)。
> 历史国家身份按当时国名独立建档,西德(FRG)、苏联(URS)、捷克斯洛伐克(TCH)、南斯拉夫(YUG)不与现代国家合并。

## 四、数据文件与重导方式

| 文件 | 内容 |
|---|---|
| `data/install.sql` | 建库建表 + 基础数据(届次、账号、团队成员) |
| `data/real_worldcup_data.sql` | 1986–2022 比赛数据 |
| `data/real_worldcup_2026.sql` | 2026 比赛数据 |
| `data/real_worldcup_2026_extras.sql` | 2026 全量名单（48 队 × 26 人）与 222 条助攻 |
| `data/player_name_zh.sql` | 球员中文名：112 条人工定稿 + 4,170 条全量补充（Wikidata/中文维基 + Bing 全名 + AI 音译兜底，见文件末尾） |
| `data/player_name_zh_2026.sql` | 2026 全量名单新增 810 名球员的中文名（中文维基/Wikidata 优先，AI 音译兜底） |
| `data/player_name_zh_2026_map.tsv` | 2026 新增球员的逐人映射（id / 原名 / 中文名 / 国籍 / 出生日期 / 来源） |
| `data/player_name_zh_map.tsv` | 全量补充的逐人映射（id / 原名 / 中文名 / 国籍 / 出生日期 / Wikidata QID / 置信分 / 来源） |
| `data/player_name_zh_all.sql` | 全量补充的独立 SQL（与 `player_name_zh.sql` 末尾同源，便于审查） |
| `data/check.sql` | 结构自检 |
| `data/demo_teams_players.sql` | 早期演示数据(已被真实数据取代,保留备查) |
| `data/demo_history_data.sql` | 早期演示数据(已被真实数据取代,保留备查) |

干净重建:

```bash
mysql -u root -p < data/install.sql
mysql -u root -p worldcup < data/real_worldcup_data.sql
mysql -u root -p worldcup < data/real_worldcup_2026.sql
mysql -u root -p worldcup < data/player_name_zh.sql
mysql -u root -p worldcup < data/real_worldcup_2026_extras.sql
mysql -u root -p worldcup < data/player_name_zh_2026.sql
```

所有数据文件都是幂等的,重复导入不会产生重复记录。

> 中文名要在 `real_worldcup_2026_extras.sql` 之前导入:`player_name_zh.sql` 部分条目用 `birth_date IS NULL` 定位,extras 会补齐生日,顺序反了会漏掉这些译名。
> `player_name_zh_2026.sql` 必须在 extras 之后导入:它补的是 extras 新建的 810 名球员。

## 五、球员中文名

`player.name` 保留原始拉丁名，`player.name_zh` 是中文名；前台默认显示原名，可切到中文名；详情页副行保留另一种姓名，搜索同时匹配两者，避免译名差异导致认不出人。

- **覆盖范围**：5,086 名球员全部有 `name_zh`。其中 4,276 条为原有译名（含 112 条人工定稿 + 4,170 条补充，去重后 4,276），810 条为 2026 全量名单新增球员的中文名（中文维基 521 条 + Wikidata 21 条 + AI 音译 268 条）。
- **译名来源**：原有 4,276 条中 3,220 条来自 Wikidata / 中文维基条目名（按出生年校验，避免同名错配）；93 条来自 Bing 词典全名；855 条为 AI 音译兜底；2 条人工修正。2026 新增 810 条中 521 条来自中文维基 2026 参赛球员名单，21 条来自 Wikidata 校验命中，268 条为 AI 音译兜底；AI 音译只保证“可读的中文名”，不保证大陆媒体统一译法。逐人来源见 `data/player_name_zh_map.tsv` 与 `data/player_name_zh_2026_map.tsv`。
- **精度说明**：Wikidata/中文维基条目名优先，冷门球员的 AI 音译只保证“可读的中文名”，不保证大陆媒体统一译法；正式发布前可按映射表抽查/替换。
- **定位方式**：两个中文名 SQL 都用 `name + nationality + birth_date` 定位，不用自增 id，干净重建后不会错配；只补 `name_zh IS NULL` 的行，不覆盖后台人工修订。
- **扩展方式**：后台「球员管理 → 编辑」可直接改中文名；批量补充时按同样格式追加 `UPDATE`，并在对应映射表中记录来源。
