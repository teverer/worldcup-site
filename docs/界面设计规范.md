# 界面设计规范

**设计原则:以清晰的信息层级和稳定的数据扫读为核心,绿色表达品牌与状态,金色只标记关键数据。**
本规范对应 `frontend/web/css/theme.css` 与 `backend/web/css/theme.css`:这两个文件是**纯 CSS**,兼容 Bootstrap 3,不依赖任何 JS 或外部库。
项目层面遵循两条约束:

1. **不引入新的 CSS/JS 框架**,避免与 Bootstrap 3 冲突;
2. **外部依赖尽量本地化**(如 ECharts 已放在 `frontend/web/js/vendor/`),保证断网或 CDN 不可用时网站仍可完整演示。

## 1. 色板
| CSS 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#F6F7F9` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 卡片、表格、表单表面 |
| `--color-surface-alt` | `#F0F3F7` | 表头、页脚、次级面板 |
| `--color-text` | `#0B1F3A` | 主文字、页头、导航底色 |
| `--color-muted` | `#6B7280` | 次要文字(白底) |
| `--color-muted-strong` | `#4B5563` | 浅灰表面上的小字号文字(保证 AA) |
| `--color-primary` | `#0E7C4A` | 品牌绿:链接、主按钮、选中态 |
| `--color-primary-dark` | `#0A5C37` | 品牌绿 hover / active |
| `--color-primary-light` | `#16A34A` | 高亮、导航选中下划线 |
| `--color-accent` | `#F2B705` | 金色:冠军、积分、重点数据 |
| `--color-accent-dark` | `#B98900` | 金色 hover / 深色底 |
| `--color-accent-ink` | `#8A6500` | 白底上的金色文字(保证 AA) |
| `--color-border` | `#E5E7EB` | 边框、分隔线 |
| `--color-danger` | `#DC2626` | 删除、错误 |
| `--color-success` | `#16A34A` | 成功状态、图标与边框 |

语义命名参考 Primer;灰阶与间距参考 Tailwind 的 4/8 体系;后台密度参考 Ant Design / Element Plus / AdminLTE 2;前台 Hero 与卡片层级参考 Start Bootstrap(BS3)。
金色 `#F2B705` 只做背景/装饰,不作为白底正文色;正文对比度以 `--color-text`(约 16:1)和 `--color-muted-strong`(约 6.8:1)为准。

## 2. 字号层级
| 变量 | 字号 | 用途 |
| --- | --- | --- |
| `--fs-xs` | 12px | 表头、辅助说明、徽标 |
| `--fs-sm` | 14px | 正文、按钮、表格 |
| `--fs-base` | 16px | 页面基础字号 |
| `--fs-lg` | 18px | 导语、卡片标题 |
| `--fs-xl` | 22px | 区块标题 |
| `--fs-2xl` | 28px | 页面标题 |
| `--fs-3xl` | 36px | Hero 主标题、关键统计 |

标题字重 600,正文 400;手机端在媒体查询中整体下调一级。数字列使用 `font-variant-numeric: tabular-nums` 保证纵向对齐。

## 3. 间距、圆角与阴影
- 间距:8/16/24/32/40/48/64/80px,对应 `--space-1` … `--space-8`;内容最大宽度 `--container: 1200px`。
- 圆角:`--radius-sm: 6px`(按钮/输入框)、`--radius-md: 10px`(卡片/面板)、`--radius-lg: 16px`(Hero)。
- 阴影:`--shadow-sm` 用于卡片,`--shadow-md` 用于 hover 与浮层,避免重阴影。
- 统一用 `.section` 控制区块上下留白,用 `.stack`、`.row-gap` 控制纵向节奏。

## 4. 组件用法
```html

<button class="btn btn-ghost" type="button">次要操作</button>
<button class="btn btn-primary is-loading" type="button">保存中</button>
<button class="btn btn-default" type="button" disabled>禁用</button>
```

```html
<!-- 卡片 -->
<div class="card card-hover">
  <div class="card-header">射手榜</div>
  <div class="card-body">内容</div>

</div>
```


## 5. 响应式
- 桌面 ≥992px:12 栏网格按 `.span-*` 展开,内容宽 1200px。
- 平板 768–991px:小跨度列合并为 6 栏,区块间距略减。
- 手机 <768px:容器左右内边距 16px,字号下调一级,所有 `.span-*` 占满 12 栏;表格放入 `.table-responsive` 横向滚动,需要时加 `.table-sticky-first` 固定首列。

## 6. 无障碍
- 正文与背景对比度 ≥4.5:1;大字号与图形 ≥3:1。金色不用于白底正文。
- 所有可交互元素保留 `:focus-visible` 焦点环;输入框 focus 有品牌绿描边与光晕。
- 按钮、表单、分页提供 hover / focus / active / disabled / loading 状态;loading 仅加 `.is-loading`。
- 表格使用 `<caption class="sr-only">`、`scope`、语义化表头;状态不能只靠颜色表达。
- 图片必须有说明性 `alt`;导航与表单保留原生语义,不破坏键盘顺序。

## 7. 接入方式
1. 引入一次即可:前台布局已用 `registerCssFile('@web/css/theme.css')` 引入;后台可在 `backend/assets/AppAsset.php` 的 `$css` 中追加 `css/theme.css`(位于 `css/site.css` 之后)。`theme.css` 必须晚于 Bootstrap 3 与 `site.css` 加载。
2. 页面视图无需改动:现有 `.card`、`.table`、`.btn`、`.badge`、`.pagination` 及模块类(`.news-card`、`.tournament-card`、`.chart-card`、`.comment-section`、`.catalog-heading` 等)会自动继承新风格;模块 CSS 文件保持不变。
3. 新页面直接使用上述组件 class;优先使用变量与工具类,不要在页面里写死颜色/间距。
4. 后台表格默认采用紧凑密度;需要更紧时加 `.table-compact`,需要固定首列时加 `.table-sticky-first`。


## 10. 信息不重复

- 同一个统计数字,在首页概览、卡片、图表说明里**只强调一次**;不要在图、表、正文三处各说一遍。
- 标题里出现的主张(如"进球最多"),紧邻处必须有对应的图或表作为证据。
- 首页只做"入口 + 概览",完整列表交给对应的列表页,避免两页堆同样内容。
