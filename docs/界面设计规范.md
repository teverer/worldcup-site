# 界面设计规范

**设计原则:以清晰的信息层级和稳定的数据扫读为核心,绿色表达品牌与状态,金色只标记关键数据。**
本规范对应 `frontend/web/css/theme.css` 与 `backend/web/css/theme.css`:这两个文件是**纯 CSS**,兼容 Bootstrap 3,不依赖任何 JS 或外部库。
本文件只保留质量底线与信息不重复;色板、字号、间距、组件令牌见 `theme.css` 与 `设计改造-00-总纲.md` 第 11 节。

项目层面遵循以下约束:


## 0. 质量底线(所有页面适用)

- **字体**:新字体自托管并随仓库提交;显示字体可用于标题、数字、品牌和关键标签,正文用系统字体保证中文阅读。
- **影响范围**:每轮独立分支、按页面或一组相关文件小步提交,保证可回滚;鼓励全局重构,不要求一次只改一个页面。
- **规则定位**:以上是下限,不是上限。视觉上更好的做法可以突破;突破时在 `docs/设计改造-00-总纲.md` 记录理由。


## 1. 信息不重复

- 同一个统计数字,在首页概览、卡片、图表说明里**只强调一次**;不要在图、表、正文三处各说一遍。
- 标题里出现的主张(如"进球最多"),紧邻处必须有对应的图或表作为证据。
- 首页只做"入口 + 概览",完整列表交给对应的列表页,避免两页堆同样内容。
