# 世界杯40年概展 —— 部署文档

> 项目：国足世界杯夺冠队
> 技术栈：PHP 8.2、MySQL 8.0、Yii2 advanced 2.0.32

## 1. 环境要求

- PHP 8.2，启用 `openssl`、`intl`、`mbstring`、`pdo_mysql`、`fileinfo`
- MySQL 8.0.16 或更高版本
- Windows PowerShell 5.1 或 PowerShell 7
- 项目根目录下的 `vendor/` 必须存在；正常 clone 后无需运行 Composer

检查 PHP：

```powershell
php -v
php -m
```

## 2. 一键部署

在项目根目录双击 `deploy.bat`，或在命令行运行：

```bat
deploy.bat
```

脚本依次执行：

1. 查找 PHP 和 MySQL
2. 检查 PHP 必需扩展
3. 缺少本地配置时运行 `php init --env=Development --overwrite=All`
4. 交互输入 MySQL 地址、端口、用户名和密码
5. 检查 `worldcup` 是否已有表；已有数据时必须输入 `RESET`
6. 导入 `data/install.sql`
7. 导入 `data/real_worldcup_data.sql`、`data/real_worldcup_2026.sql`、`data/player_name_zh.sql`（球员中文名，可重复执行）
8. 写入 `common/config/main-local.php` 并运行 `data/check.sql`
9. 在 8080 和 8081 端口启动前后台

> 已有库升级：执行 `data/comment_site_target.sql`，给 `comment.target_type` 增加 `site`（全站留言簿）；脚本可重复执行。全新安装的 `install.sql` 已包含该目标，无需单独执行。
>
> 资讯口径：执行 `data/news_announcement_fix.sql`，把《本站上线公告》的「1986–2022 十届 604 场」更新为「1986–2026 十一届 708 场 1832 球」；有则更新、无则插入，可重复执行。

部署完成后的地址：

- 前台：<http://localhost:8080>
- 后台：<http://localhost:8081/site/login>
- 管理员：`admin / admin123`

> 后台顶栏「查看前台」读取 `common/config/params.php` 的 `frontendUrl`，默认 `http://localhost:8080`；换端口或域名时在 `common/config/params-local.php` 覆盖，不要改后台路由。

`admin123` 仅用于课程演示，正式公网部署前必须修改。

## 3. 手动还原

### 3.1 初始化

```powershell
php init --env=Development --overwrite=All
```

如果 `frontend/config/main-local.php` 已存在，不应再次覆盖，除非明确需要重置本地配置。

### 3.2 创建数据库

```powershell
mysql -u root -p --execute="SOURCE data/install.sql"
mysql -u root -p worldcup --execute="SOURCE data/real_worldcup_data.sql"
mysql -u root -p worldcup --execute="SOURCE data/real_worldcup_2026.sql"
mysql -u root -p worldcup --execute="SOURCE data/player_name_zh.sql"
mysql -u root -p worldcup --execute="SOURCE data/module1_team_data.sql"
mysql -u root -p --execute="SOURCE data/check.sql"
```

`install.sql` 会删除并重建业务表。已有数据的环境必须先备份。

### 3.3 数据库配置

编辑 `common/config/main-local.php`：

```php
'dsn' => 'mysql:host=127.0.0.1;port=3306;dbname=worldcup;charset=utf8mb4',
'username' => 'root',
'password' => '你的密码',
'charset' => 'utf8mb4',
```

也可以使用脚本根据环境变量生成，密码不会输出到终端：

```powershell
$env:WC_DB_HOST = '127.0.0.1'
$env:WC_DB_PORT = '3306'
$env:WC_DB_NAME = 'worldcup'
$env:WC_DB_USER = 'root'
$env:WC_DB_PASSWORD = '你的密码'
php tools/apply-db-config.php
```

### 3.4 启动

```powershell
php yii serve --port=8080 --docroot=frontend/web
php yii serve --port=8081 --docroot=backend/web
```

两条命令需要在两个终端中分别运行。

## 4. 上传目录

确保以下目录可写：

- `frontend/runtime/`
- `backend/runtime/`
- `frontend/web/assets/`
- `frontend/web/uploads/team/`
- `data/team/`
- `data/personal/`

团队 Logo、成员照片保存到 `frontend/web/uploads/team/`。作业文件保存到 `data/team/` 和 `data/personal/`，由下载控制器校验路径后发送。

## 5. 验收

```powershell
curl.exe -I http://localhost:8080/
curl.exe -I "http://localhost:8080/index.php?r=team-info%2Findex"
curl.exe -I "http://localhost:8080/index.php?r=team-info%2Fdownloads"
curl.exe -I http://localhost:8081/site/login
php -l common/models/Work.php
```

管理员登录后应能打开团队信息、成员管理和作业管理页面。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `php` 不是内部或外部命令 | 将 PHP 目录加入 PATH，或设置 `PHP_EXE` 后运行部署脚本 |
| PHP 缺少 `pdo_mysql` | 在 `php.ini` 启用 `extension=pdo_mysql` |
| MySQL 拒绝连接 | 启动 `MySQL80` 服务并检查端口、账号和密码 |
| 页面显示数据库不存在 | 运行 `data/install.sql` |
| CSS、JS 修改后不生效 | 删除 `frontend/web/assets/` 下生成的哈希目录 |
| 上传失败 | 检查上传目录是否存在并具有写权限 |
| 下载返回 404 | 检查 `work.file_path` 指向的文件是否位于 `data/team/` 或 `data/personal/` |
