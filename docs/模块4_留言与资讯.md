# 模块④：留言与资讯

> 完成日期：2026-11-17
> 负责人：石子川 2411966
> 分支：`feature/comment`

## 一、功能范围

模块④负责前台资讯展示、实体留言和后台资讯/留言管理，主要涉及以下数据表：

- `comment`
- `comment_like`
- `news`

当前支持五种留言目标：

| `target_type` | 页面 |
|---|---|
| `team` | 球队详情 |
| `player` | 球员详情 |
| `game` | 比赛详情 |
| `news` | 资讯详情 |
| `tournament` | 届次详情 |

最新 `dev` 已经提供比赛和届次页面。本分支已保留通用留言组件；合并最新前端代码后，可直接在对应详情页调用组件。

## 二、前台功能

### 资讯

| 功能 | 路由 |
|---|---|
| 资讯列表和搜索 | `index.php?r=news/index` |
| 资讯详情 | `index.php?r=news/view&id=1` |

规则：

1. 前台只查询 `status=1` 的资讯。
2. 草稿直接访问返回 404。
3. 列表按发布时间倒序分页，每页 10 条。
4. 搜索范围包括标题和作者。
5. 正文保存前由 HTMLPurifier 清理危险标签，展示时再次清理。

### 留言

游客可以查看留言。发表、回复、点赞和删除必须登录。

| 操作 | 规则 |
|---|---|
| 发表 | 内容 1–5000 字，只能挂载到已存在实体 |
| 回复 | 父留言必须有效，且目标类型和目标 ID 必须相同 |
| 点赞 | 同一用户对同一条留言只能点赞一次 |
| 删除 | 作者删除自己的留言，管理员可删除任意留言 |
| 删除效果 | 当前留言和全部后代回复设置为 `status=1` |

留言正文按纯文本转义输出，不解析用户输入 HTML。

### 可复用组件

在前台详情页中调用：

```php
use common\components\CommentTarget;
use frontend\widgets\CommentSection;

echo CommentSection::widget([
    'targetType' => CommentTarget::GAME,
    'targetId' => $model->id,
]);
```

组件会完成：

- 有效留言查询
- 回复树组装
- 用户信息加载
- 点赞数量和当前用户点赞状态查询
- 表单、点赞和删除按钮渲染

### 前台展示（2026-11-23 改版）

- 组件仍是 `CommentSection`，展示层改为“留言簿”：时间轨 + 名字印章 + 一级回复 + 同感；空态给三个可点的记忆起点。
- 发帖 / 回复 / 同感后回到 `#comment-<id>`；删除后回 `#comments`；登录 / 注册带 `returnUrl` 回原页。
- 旧 `.comment-*` 样式不再用于新结构；新样式在 `design-v2.css` 第 14 节。

## 三、后台功能

### 资讯管理

入口：后台 `index.php?r=news/index`。

- 新增、查看、编辑、删除资讯
- 按标题或作者搜索
- 按草稿/已发布筛选
- 首次发布自动填写 `publish_time`
- 封面上传支持 JPG、PNG、WebP、GIF，最大 5 MB
- 上传文件保存到 `frontend/web/uploads/news/`
- 替换封面时删除无其他资讯引用的旧文件
- 删除资讯时同时删除其多态留言和当前封面

### 留言管理

入口：后台 `index.php?r=comment/index`。

- 按内容、用户名或昵称搜索
- 按留言目标和状态筛选
- 管理员执行软删除
- 父留言删除时同步隐藏整棵回复树
- 记录删除数量，便于判断是否影响回复

## 五、安全设计

- 所有新增操作使用 POST。
- 所有写操作由 Yii2 CSRF 校验保护。
- 游客不能直接调用留言写入接口。
- `user_id` 从当前登录用户获得，不接受表单传入。
- `target_type` 使用固定白名单。
- 回复目标与父留言一致性在表单和 Active Record 两层校验。
- 点赞由数据库唯一索引 `uk_comment_user` 兜底。
- 普通用户不能删除他人留言，管理员权限由 `role >= 1` 校验。
- 留言直接转义，资讯 HTML 使用 HTMLPurifier。
- 上传扩展名和 MIME 类型同时校验，文件名由服务端随机生成。

## 六、演示数据

```powershell
  mysql --default-character-set=utf8mb4 -u root -p worldcup
```

脚本可重复执行，包含：

- 1 条已发布资讯
- 1 条草稿资讯
- 球队、球员、比赛、资讯、届次留言
- 资讯回复
- 2 条点赞记录
