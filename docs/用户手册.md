# 世界杯数据门户网站 —— 用户手册

> 团队：国足世界杯夺冠队
> 整理日期：2026-11-28
> 适用版本：`dev` 整合版
> 截图状态：待最终界面截图补充

## 一、网站简介

“世界杯40年概展”是面向 1986–2026 年世界杯的数据门户，提供：

- 历届世界杯届次、分组、淘汰赛、冠军和赛事统计
- 球队、球员、比赛、名单、进球和助攻数据
- 新闻、公告和团队信息
- 登录用户留言、回复、点赞和删除自己的留言
- 管理员维护赛事数据、球队球员、新闻、留言和团队主页

## 二、启动与访问

### Windows 本地快捷方式

双击：

```text
E:\GPA\tools\start-worldcup.cmd
```

等待提示本地环境已经运行，然后打开：

| 入口 | 地址 |
|---|---|
| 前台 | http://localhost:8080 |
| 后台 | http://localhost:8081 |

停止网站：

```text
E:\GPA\tools\stop-worldcup.cmd
```

### 使用 PHP 内置服务器

在项目根目录分别运行：

```powershell
php yii serve --port=8080 --docroot=frontend/web
php yii serve --port=8081 --docroot=backend/web
```

### 演示账号

| 角色 | 用户名 | 密码 | 可访问范围 |
|---|---|---|---|
| 普通用户 | `demo` | `admin123` | 前台浏览、留言、回复、点赞 |
| 管理员 | `admin` | `admin123` | 前台功能及全部后台管理 |

演示密码只用于本地测试，正式部署前应修改。

## 三、前台导航

前台主导航包含：

1. **首页**：历届世界杯记分牌墙和讨论区
2. **比赛**：决赛精选和全部比赛记录
3. **球队**：按名称、FIFA 代码和大洲浏览球队
4. **球员**：搜索球员、按球队和位置筛选
5. **资讯**：搜索并阅读已发布资讯
6. **关于与文档**：团队介绍、作业文件、统计口径和源码入口
7. **登录**：进入注册或登录页面

登录后，导航右侧显示当前用户昵称或登录名，以及“退出”按钮。

## 四、首页与届次浏览

### 首页记分牌墙

1. 打开前台首页。
2. 页面按年代展示 1986–2026 年历届世界杯。
3. 点击任意届次的记分牌进入该届详情。

届次详情通常包含：

- 主办国、参赛队数、赛制说明
- 小组赛积分与排名
- 淘汰赛晋级树
- 冠军、决赛和关键统计
- 该届留言区

### 阅读赛事统计

页面中的图表和统计由比赛、进球和球队数据实时聚合：

- 1986、1990 年胜场积分为 2 分
- 1994 年及以后胜场积分为 3 分
- 射手榜排除乌龙球和点球大战进球
- 球队进球数按进球归属球队统计

## 五、比赛浏览

1. 点击导航“比赛”。
2. 默认展示历届决赛精选。
3. 点击“看全部比赛”可进入全部比赛记录。
4. 使用筛选栏按球队、届次、阶段和小组查询。
5. 点击比赛条目进入详情。

决赛列表中的“回到十一场决赛”可恢复默认范围。

比赛详情展示：

- 主客队、比赛时间和阶段
- 常规时间及加时比分
- 点球大战比分（如存在）
- 比赛场地与状态
- 进球、助攻和乌龙球记录
- 比赛留言区

## 六、球队浏览

1. 点击导航“球队”。
2. 按名称或 FIFA 代码搜索。
3. 按亚洲、欧洲、非洲、北美洲、南美洲或大洋洲筛选。
4. 点击球队卡片进入详情。

球队详情包含：

- 队名、代码、所属大洲和简介
- 国旗或队徽
- 历届参赛届次
- 按届次查看的球员名单
- 球队留言区

## 七、球员浏览

1. 点击导航“球员”。
2. 输入球员姓名或国籍搜索。
3. 按代表球队和场上位置继续筛选。
4. 首页中的射手榜入口可直接查看每届最佳射手。
5. 点击球员进入详情。

球员详情包含：

- 姓名、国籍、位置、出生日期和照片
- 历届代表球队、球衣号和位置
- 世界杯进球和助攻统计
- 球员留言区

统计以已结束比赛为准，不包含乌龙球和点球大战进球。

## 八、资讯

1. 点击导航“资讯”。
2. 在搜索框输入标题或作者关键词。
3. 点击资讯卡片或“阅读全文”。
4. 资讯详情展示发布时间、作者、正文、封面和留言区。

前台只显示“已发布”资讯。草稿不会出现在列表中，直接访问草稿地址会提示不存在。

## 九、注册、登录与退出

### 注册

1. 点击导航中的“登录”进入认证页面。
2. 选择注册入口。
3. 填写登录名、昵称和密码。
4. 密码长度不能少于 6 位。
5. 提交后使用新账号登录。

### 登录

1. 点击导航中的“登录”。
2. 输入用户名和密码。
3. 登录成功后返回原页面或首页。

### 退出

点击页头右侧的“退出”按钮。退出后不能继续发表留言或点赞。

## 十、留言、回复与点赞

游客可以阅读留言，但发表、回复、点赞和删除需要登录。

### 发表留言

1. 登录后进入届次、比赛、球队、球员或资讯详情页。
2. 找到页面下方留言区。
3. 输入留言内容。
4. 点击“发表留言”。
5. 页面刷新后显示新留言。

留言最多 5000 字，纯文本展示，不解析 HTML。

### 回复

1. 点击目标留言下方的“回复”。
2. 输入回复内容。
3. 点击“发表回复”。
4. 回复显示在父留言下方。

回复必须与父留言属于同一实体，不能跨页面挂载。

### 点赞

点击留言下方的“赞”。同一用户对同一条留言只能点赞一次，点赞后显示当前数量。

### 删除

- 普通用户可以删除自己发表的留言。
- 管理员可以删除任意留言。
- 删除父留言后，全部回复同时从前台隐藏。

## 十一、后台登录与工作台

1. 打开后台地址 http://localhost:8081。
2. 使用管理员账号登录。
3. 登录后进入后台工作台。

后台左侧导航分为：

| 分组 | 功能 |
|---|---|
| 赛事数据 | 届次、参赛队、名单、比赛、进球 |
| 球队与球员 | 球队、球员 |
| 内容与社区 | 资讯、留言 |
| 团队主页 | 团队信息、成员、作业文件 |

普通用户即使拥有前台账号，也不能登录后台。

## 十二、后台赛事数据管理

### 届次

维护年份、名称、东道主、参赛队数、赛制、积分规则、开始和结束日期。

年份必须唯一。删除届次可能级联删除该届参赛队、名单、比赛和进球，必须确认。

### 参赛队

为某届添加参赛球队，并维护小组、主教练、FIFA 排名和最终名次。

同一届的同一球队只能录入一次。

### 名单

将球员加入某届某队，填写球衣号和该届位置。

同一名球员在一届世界杯中只能代表一支球队；同一球队同届球衣号不能重复。

### 比赛

维护比赛时间、阶段、场地和状态，录入常规时间、加时、点球大战比分。

已结束比赛必须填写主客队比分；主队和客队不能相同。

### 进球

为比赛录入进球球员、进球所属球队、助攻球员、分钟和进球类型。

乌龙球的进球归属球队填写受益方；点球大战进球必须标记，避免污染射手榜。

## 十三、后台球队与球员管理

### 球队

- 新增、查看、编辑、删除球队
- 维护名称、FIFA 代码、大洲、图片路径和简介
- 球队名称和非空代码必须唯一

已有比赛、名单、进球或留言关联时，系统会禁止删除。

### 球员

- 新增、查看、编辑、删除球员
- 维护姓名、出生日期、国籍、位置、照片和简介
- 出生日期不能晚于当天

图片填写 `images/` 或 `uploads/` 下的站内相对路径，文件本体需要提前放置。

## 十四、后台资讯管理

1. 点击“内容与社区 → 资讯”。
2. 可按标题或作者搜索，并按草稿/已发布筛选。
3. 点击“新增资讯”填写标题、作者、正文和状态。
4. 可上传 JPG、PNG、WebP、GIF 封面，最大 5 MB。
5. 选择“已发布”后保存，资讯立即出现在前台。
6. 编辑时可上传新封面，旧封面会在不再被引用时删除。
7. 删除资讯时，其留言和封面文件一并清理。

资讯正文支持基础 HTML，保存时自动清理脚本和危险标签。

## 十五、后台留言管理

1. 点击“内容与社区 → 留言”。
2. 按留言内容、用户名、昵称、留言目标或状态筛选。
3. 点击“删除”并二次确认。
4. 被删除留言保留“已删除”状态，不在前台显示。
5. 删除父留言时，其全部回复同步隐藏。

## 十六、团队主页与作业文件

后台“团队主页”用于维护：

- 团队名称、Logo、口号和介绍
- 团队成员姓名、学号、分工、照片和简介
- 团队作业和个人作业文件

前台“关于与文档”页面展示团队信息、统计口径、作业下载和源码入口。

## 十七、常见问题

### 页面打不开

确认 MySQL、前台和后台服务已启动：

```text
E:\GPA\tools\start-worldcup.cmd
```

### 登录失败

检查用户名和密码，并确认账号存在于当前数据库。普通用户不能登录后台。

### 看不到留言输入框

留言必须登录后使用，请确认页头已显示当前昵称。

### 资讯草稿打不开

草稿仅后台可见，请将状态改为“已发布”。

### 封面或图片不显示

确认文件位于正确上传目录，数据库保存的是站内相对路径，而不是电脑本地绝对路径。

### 删除失败

球队、球员、球队成员或用户被历史数据引用时不能直接删除。先处理关联记录，再尝试删除。

### 重复数据提示

球队名称、FIFA 代码、届次年份、成员学号、同一届球员名单和同队球衣号均受唯一约束。
