## 1. 设计 brief

- 站点：世界杯历史档案 + 社区讨论，1986–2026，十一届。
- 访客：课程评审 / 泛球迷 / 社区参与者 / 管理员。
- 主路径：根（记分牌墙）→ 届次 → 晋级图 / 积分 / 射手 → 单场。
- 优先级：**感觉 > 可信 > 扫读 > 社区**。
- **感觉**：第一眼的气质、进入页面时的情绪、想不想继续看下去。
- **回忆**：离开后还能想起的一个画面、一句话或一个比分，是感觉的副产品。
- 第一屏任务：让访客先有感觉，再记住一个真实瞬间，并知道下一步点哪；不编造数据。

## 4. 信息架构

- **根 = 记分牌墙**，取消独立首页。
- 主导航 5 项：届次 / 比赛 / 球队 / 球员 / 资讯；“纪录”为二级入口。
- 三种页面原型：索引页 / 记录页 / 表单页。
- 完整内容只在归属页；其他页面允许一行摘要 + 链接。

## 6. 层级与内容预算

**四层：**

```text
站点   届次主轴  我从哪进？   5 个入口 + 记分牌墙
页面   身份头    我在哪？     大标题 + 一句上下文 + 一个主操作
区块   标题+证据  这里有什么？ 标题 → 一句说明 → 表/图 → 一个链接
行     标记+名称  我点哪个？   年份/代号 + 名称 + 元信息 + 动作
```

**视觉编码：**

- 字号层级少而清楚：年份 / 比分 → 页面标题 → 区块标题 → 正文 → 元信息。
- 颜色 4 义：藏青 = 结构，绿 = 动作，金 = 成就（冠军 / 纪录），灰 = 辅助；红只给点球 / 加时 / 危险。
- 密度节奏：根低 → 届次高 → 比赛详情低 → 球队 / 球员中 → 资讯低。
- 每页一个实心主按钮，其余为文字链接。

**三条减法：**

1. 主导航 5 项；“纪录”降为二级入口。
2. 届次首屏只放身份头 + 一个舞台（默认淘汰赛纵向树）；小组赛 / 统计在同一舞台切换。
3. 删除所有“最近 / 热门 / 推荐”模块。

## 7. 硬规则

- 一个事实只完整出现一次；允许一行摘要 + 链接。
- 只设计有数据支撑的区块；不伪造队徽、头像、阵容、直播文案。
- 每页一个主操作；每屏回答“我在哪 / 这里有什么 / 下一步点哪”。
- 键盘焦点可见、尊重 `prefers-reduced-motion`、正文对比度 ≥ 4.5:1、三档宽度无页面级横向溢出。
- 禁止：全大写英文 eyebrow、每个链接加 `→`、同款圆角卡、渐变占位图、假直播文案。

### 7.1 反保守条款

- 本总纲和设计规范是**下限**，不是上限。
- 当规则与“感觉”冲突时，先提出突破方案，说明为什么更好，记录在此；不要为了守规则牺牲视觉。
- 可以突破：版式数量、字号层级、色彩比例、动效强度、页面数量。
- 不可突破：真实数据、功能可用、键盘焦点、`prefers-reduced-motion`、390 / 768 / 1440 无页面级横向溢出、正文对比度。

### 11.4 红 / 金 / 绿纪律

- **金**：只给冠军、纪录、奖杯数字；不用于按钮、普通强调、标题装饰。
- **红**：只给决胜、只做小面积、只和“改变命运”绑定；普通链接不用红；后台危险动作另用 `--danger`。
- **绿**：深绿只做面，亮绿只做动作；深色底上不用深绿写字。
- **泛光白**：深色区最亮的东西，只给比分和最重要的数字。
- **冷纸**：带一点冷绿灰，不用暖黄纸，避免变成复古剪贴簿。

### 11.5 野性的来源

- 直角：0–4px 圆角，记分牌是硬边，不是软卡片。
- 数字：`Saira Condensed` 做大年份和比分，字号 64–120；中文标题用重黑体、紧字距。
- 一条粉笔线：深色牌顶部 1px 泛光白（20%），像边线，不铺满。
- 一条哨声线：红色只在决胜处做 2px 短线或小徽标。
- 灯光：深色面用极淡顶部径向光 + 细颗粒，不用纯平 `#000`。
- 动效：只给“展开一届”“比分出现”，不做滚动入场。

### 11.6 可调旋钮

- 更燃：多一点红、多一点深色，点球用暗场红；金仍然克制。
- 更辉煌：金多一点，纪录页整页深色 + 金；按钮仍不用金。
- 更静：纸面更多，红更少，深色只留根页和身份头。
- 更野：直角、数字再大、场绿再深、红哨线更多、留白更少。
- 更高级：金更哑光、泛光白留白更多、红更少、去掉除灯光外的所有渐变。

### 11.7 2026-11-23 修订：夜场极光（已推翻“雨夜”）

- **推翻原因**：用户指出本站不是情感站，雨和世界杯关系弱；“雨夜”更像电影海报。保留“夜场”这个场域，但把天气换成**球场灯光**。
- **深色入口**：夜场极光 = 3–4 团极慢漂移的青绿 / 深蓝 / 金的光晕，叠一层 30px 点阵与透视球场线。它表达的是“夜里的球场灯”，不是“极光”。
- **纪录页（未落地）**：单独用“黑金颁奖”——只保留黑、白、金，同心圆环 + 金色微尘；不出现青绿极光。根页是“入场”，纪录页是“颁奖”。
- **纸面数据**：暖纸 `#EFEDE5`、细线 `#D8D2C3`、墨黑 `#0B1418`、哑光金 `#82590B`（纸面文字）/ `#E0B457`（深色）、深绿 `#0E5138`。去掉白卡阴影、荧光绿按钮、左侧粗绿条。
- **标题字**：得意黑（Smiley Sans，OFL）只用于标题 / 队名 / 展签；拉丁人名与正文不用它。数字仍用 Saira Condensed。
- **动效**：极光 40–58s 漂移；记分牌随指针亮灯；悬停某一届时夜场色温切到那一届的年代色；入场只做一次性 12px 上浮。尊重 `prefers-reduced-motion`。
- **纪律不变**：金只给冠军 / 纪录 / 获奖；红只给决胜与危险；深绿只做面，亮绿只做动作。

### 11.8 2026-11-23 后台：工作间（与前台明确区分）

- **定位**：前台是夜场，后台是工作间。后台不做背景动画，优先密度、扫读和批量操作；它必须一眼看出“这不是给访客看的页面”。
- **骨架**：固定石墨导轨（工作台 + 4 组模块）替代原来的顶部导航；右侧是暖纸工作区，带极淡的方格纸纹理和铜色页面标记。
- **配色**：导轨 `#151B18`、暖纸 `#F2F0E9`、面板 `#FAF8F2`、铜色 `#C98A2E`、工作绿 `#2F6B57`、危险红 `#A8232F`。铜色是后台独有的标记色，和前台的金色区分开。
- **字体**：得意黑只用于页标题和面板标题；数字 / 编号 / 日期用 Saira Condensed；表格、表单、按钮用系统字。
- **表格**：行高和字号优先密度；操作列在横向滚动时钉在右侧；比赛列表的场地列允许换行。筛选表单保持一行，不套用新增 / 编辑表单的面板。
- **表单**：新增 / 编辑是一张居左的登记表（最大宽度受限），两侧留白，不铺满整个工作区。
- **登录**：不显示导轨，表单在纸面工作区居中；仍有工作台 / 面包屑作为上下文。
- **移动端**：导轨收成抽屉，顶部只有一个菜单按钮；工作区单列，表格内部横滚，不产生页面级横向溢出。
- **不动**：后台权限、路由、CRUD 逻辑、GridView 列定义、工作台数据口径。

## 16. 索引页：比赛 / 球队 / 球员（2026-11-23）

**任务**：三页都是「从很多个里找到一个」。共用同一套索引页骨架，每页只换默认状态、筛选和行。

**共同骨架**：身份头 → 检索行 → 结果区 → 空态。标题平行（比赛 / 球队 / 球员，不叫「目录」）；整行可点；三档宽度不溢出。

## 17. 留言簿（讨论区，2026-11-23）

**一句话**：一条留言是这一页档案里的一条带日期的记录，不是信息流。

### 17.1 为什么推翻“看台”

- 旧方案把比喻当成了规格：深绿通栏 + 折叠条 + 纸卡 + 登录横幅 + 虚线空框。结果讨论区像第三方插件，而不是这一页的一部分。
- 具体问题：三个盒子叠在一起；登录按钮抢页面主操作；空态像“内容没加载出来”；标题和计数重复；回复靠左边框缩进；发帖后回到页顶，没有任何“你的留言到了”的反馈。
- 用户要求不局限于“看台”这一种比喻，先把评论区本身设计好。
- 顶级站点的共性：一条主线而不是一堆盒子；嵌套最多两级；操作默认退后；空态和输入框是编辑型排版的一部分。它们的盲区是为海量评论设计，空态常是补丁。
- 我们的机会：这是一个体量很小、以“记忆”为核心的世界杯档案。为第一条留言设计，比复制一个通用评论区更有价值。

### 17.2 结构

- **标题**：全站统一叫“留言簿”，不再有“届次留言 / 比赛留言 / 资讯留言 / 看台”四种叫法；有留言时显示条数与人数，0 条时不显示计数。
- **提问**：每个目标页一句，不写“添加评论”。届次问“这一届，你记住了哪一夜？”，比赛问“这一场，你记得哪一刻？”，球队问“你和这支球队，从哪一届开始？”，球员问“关于他，你记得哪一个球？”，资讯问“读完这一篇，你想起了什么？”。
- **输入行**：左侧是“今天”的时间位，右侧是名字印章和输入框；游客只看到一句“登录后，在这一页留一笔”，没有实心登录按钮、没有横幅。
- **记录**：左侧时间轨（日期 / 时间，时间本身就是这条记录的永久链接）；右侧名字印章、姓名、正文、同感 / 回复 / 删除。回复只缩进一级；更深的回复拍平，写“回复 @某人”；同一父记录超过两条回复默认折叠。
- **空态**：一句话“这一页还没有人留言”，加三个可点的记忆起点；点击后直接填进输入框。游客不显示起点，只显示登录邀请。
- **位置**：比赛 / 球队 / 球员 / 资讯在正文之后；届次在上一届 / 下一届之后。不再有深绿“看台”折叠条。

### 17.3 规则

- 一个事实只出现一次：标题不重复页面对象，计数只在有留言时出现。
- 登录是安排，不是主操作：不做实心按钮、不做通栏提示条。
- 身份诚实：首字印章 + 稳定深色；不做假头像、不做彩虹头像。
- 互动克制：用“同感”而不是“赞”；不做热度排行、不做“热门 / 最新”排序。
- 发帖、回复、同感后都落在自己的记录上（`#comment-id`）；删除后回 `#comments`；登录 / 注册带 `returnUrl` 回原页。
- 视觉只用站内语言：暖纸、细线、墨黑、深绿动作；金不用于同感；标题用得意黑，数字用 Saira，正文用系统字体。
- 键盘焦点可见；`Ctrl / Cmd + Enter` 提交；回复框展开后聚焦；`prefers-reduced-motion` 下不使用到达动画。
- 不伪造数据、头像、热度；当前体量不引入排序、分页、富文本、@提醒。

### 17.4 不做什么

- 不做深绿看台折叠条、不做卡片套卡片、不做虚线空框、不做全大写英文 eyebrow。
- 不在评论区重复页面标题、比分、统计口径。
- 不做头像墙、不做“正在讨论 / 热门留言”之类的伪社交证明。

### 17.5 验收

- 390 / 768 / 1440 无页面级横向溢出；正文对比度 ≥ 4.5:1。
- 游客可读、不能写；登录后输入框可用；空态起点能填入；`Ctrl / Cmd + Enter` 可提交。
- 发帖 / 回复 / 同感后 URL 带 `#comment-id` 并有一次短促的到达提示；删除后回 `#comments`；直达折叠回复会自动展开。
- 回复只缩进一级；超过两条折叠；深层回复显示“回复 @某人”。
- 登录 / 注册后回到原页留言簿（`#comments`）。
- 键盘可操作：回复、收起、展开、同感、删除；焦点可见。
- 自检：`php -l`、五个详情页 `curl` 200、三档宽度截图。
