## 1. 设计 brief

- 站点：世界杯历史档案 + 社区讨论，1986–2026，十一届。
- 访客：课程评审 / 泛球迷 / 社区参与者 / 管理员。
- 主路径：根（记分牌墙）→ 届次 → 晋级图 / 积分 / 射手 → 单场。
- 优先级：**感觉 > 可信 > 扫读 > 社区**。
- **感觉**：第一眼的气质、进入页面时的情绪、想不想继续看下去。
- **回忆**：离开后还能想起的一个画面、一句话或一个比分，是感觉的副产品。
- 第一屏任务：让访客先有感觉，再记住一个真实瞬间，并知道下一步点哪；不编造数据。

## 2. 审计结论（摘要）

- **P0**：后台仍是 Yii 默认欢迎页；全站存在两套设计语言；目录与详情页大量空白；缺少队徽 / 肖像等档案素材；标题字体无性格。
- **P1**：全大写英文 eyebrow、尾随箭头、统一圆角卡、渐变占位图；颜色语义不稳；导航缺入口；后台 Gii 默认；空 / 加载 / 错误三态不全；图表与正文同质。
- **P2**：页脚弱；登录页空；首页 1832 球与 CLAUDE.md 2045 球口径不一致；长页面缺定位。

## 3. 保留 / 推翻

**保留的是信息价值，不是外观：**

- 年份作为锚点、冠军摘要、晋级图 / 图表 / 口径说明。
- 键盘焦点、`prefers-reduced-motion`、表格语义、空态等质量底线。
- 后台“效率优先”的定位与紧凑密度。

**推翻的是视觉语言：**

- 独立 dashboard 首页、灰底白卡默认骨架。
- 全大写英文 eyebrow、每个链接都加 `→`、同一套圆角卡 + 阴影、渐变占位图。
- Gii 默认后台首页。

## 4. 信息架构

- **根 = 记分牌墙**，取消独立首页。
- 主导航 5 项：届次 / 比赛 / 球队 / 球员 / 资讯；“纪录”为二级入口。
- 三种页面原型：索引页 / 记录页 / 表单页。
- 完整内容只在归属页；其他页面允许一行摘要 + 链接。

## 6. 层级与内容预算

**四层：**

```text
站点   届次主轴  我从哪进？   5 个入口 + 记分牌墙
页面   身份头    我在哪？     大标题 + 一句上下文 + 一个主操作
区块   标题+证据  这里有什么？ 标题 → 一句说明 → 表/图 → 一个链接
行     标记+名称  我点哪个？   年份/代号 + 名称 + 元信息 + 动作
```

**视觉编码：**

- 字号 5 级：年份 / 比分 → 页面标题 → 区块标题 → 正文 → 元信息；一屏最多 3 级。
- 颜色 4 义：藏青 = 结构，绿 = 动作，金 = 成就（冠军 / 纪录），灰 = 辅助；红只给点球 / 加时 / 危险。
- 密度节奏：根低 → 届次高 → 比赛详情低 → 球队 / 球员中 → 资讯低。
- 每页一个实心主按钮，其余为文字链接。

**三条减法：**

1. 主导航 5 项；“纪录”降为二级入口。
2. 届次首屏只放身份头 + 一个舞台（默认淘汰赛纵向树）；小组赛 / 统计在同一舞台切换。
3. 删除所有“最近 / 热门 / 推荐”模块。

## 7. 硬规则

- 一个事实只完整出现一次；允许一行摘要 + 链接。
- 只设计有数据支撑的区块；不伪造队徽、头像、阵容、直播文案。
- 每页一个主操作；每屏回答“我在哪 / 这里有什么 / 下一步点哪”。
- 键盘焦点可见、尊重 `prefers-reduced-motion`、正文对比度 ≥ 4.5:1、三档宽度无页面级横向溢出。
- 禁止：全大写英文 eyebrow、每个链接加 `→`、同款圆角卡、渐变占位图、假直播文案。

### 7.1 反保守条款

- 本总纲和设计规范是**下限**，不是上限。
- 当规则与“感觉”冲突时，先提出突破方案，说明为什么更好，记录在此；不要为了守规则牺牲视觉。
- 可以突破：C5 / C6、版式数量、字号层级、色彩比例、动效强度、页面数量。
- 不可突破：真实数据、功能可用、键盘焦点、`prefers-reduced-motion`、390 / 768 / 1440 无页面级横向溢出、正文对比度。

### 11.5 红 / 金 / 绿纪律

- **金**：只给冠军、纪录、奖杯数字；不用于按钮、普通强调、标题装饰。
- **红**：只给决胜、只做小面积、只和“改变命运”绑定；普通链接不用红；后台危险动作另用 `--danger`。
- **绿**：深绿只做面，亮绿只做动作；深色底上不用深绿写字。
- **泛光白**：深色区最亮的东西，只给比分和最重要的数字。
- **冷纸**：带一点冷绿灰，不用暖黄纸，避免变成复古剪贴簿。

### 11.6 野性的来源

- 直角：0–4px 圆角，记分牌是硬边，不是软卡片。
- 数字：`Saira Condensed` 做大年份和比分，字号 64–120；中文标题用重黑体、紧字距。
- 一条粉笔线：深色牌顶部 1px 泛光白（20%），像边线，不铺满。
- 一条哨声线：红色只在决胜处做 2px 短线或小徽标。
- 灯光：深色面用极淡顶部径向光 + 细颗粒，不用纯平 `#000`。
- 动效：只给“展开一届”“比分出现”，不做滚动入场。

### 11.7 可调旋钮

- 更燃：红 2% → 3%，深色 30% → 40%，点球用暗场红；金保持 ≤5%。
- 更辉煌：金 5% → 7%，纪录页整页深色 + 金；按钮仍不用金。
- 更静：冷纸 70% → 80%，红降到 1%，深色只留根页和身份头。
- 更野：直角、数字再大、场绿再深、红哨线更多、留白更少。
- 更高级：金更哑光、泛光白留白更多、红更少、去掉除灯光外的所有渐变。

## 14. 第 3 步 · 届次详情页规格（2026-11-22 定稿）

**一句话**：一个页面，一个舞台。决赛在顶，从 16 强往下展开；小组赛和统计在同一个舞台切换。

### 14.1 页面结构

面包屑 → 紧凑记分牌头（年份 / 届次名 / 东道主 / 冠军 / 决赛一行 / 4 项 facts）→ 本地 tab（淘汰赛 / 小组赛 / 统计；讨论在右侧 + 评论数）→ 舞台（一次一个视图）→ 讨论（安静单列）→ 上一届 / 下一届细条。

- 记分牌头深色，约 220px，不是大 hero；第一屏很快进入舞台。
- 三个 tab 用文字下划线，不用胶囊；原生链接 + CSS `:target` / `:has`；保留 `#knockout` / `#groups` / `#charts` / `#comments`；无 JS 时三个面板全部可见。
- 讨论不做第四个 tab，放在舞台下方；右侧“讨论 N”是锚点链接。

### 14.2 淘汰赛视图：纵向树

- **决赛在最上方**，半决赛、1/4、1/8 依次向下；每一轮横向排开，从下往上收束到决赛。
- **从 16 强开始**。1986–2022 的淘汰赛就是 16 强；2026 的 1/16（32 强）放在树下方的“首轮 1/16 · 16 场”折叠区，4 列紧凑列表。
- 主树最宽是 1/8 的 8 列；1280 / 1366 / 1440 都要一屏放下主树，不横向滚动。
- 卡片只用中文名 + 比分；不用 PAR / FRA 代码；国旗可选，历史球队用对应历史旗，映射不全就只放名字。
- 胜者加粗；不要加时 / 点球徽章、不要“详情”行；整卡可点，细节在比赛详情。
- 决赛卡最大，冠军名字金色；半决赛 / 1/4 / 1/8 逐层变小。
- 冠军路径用金 / 绿线从 1/8 连到决赛，其他连线灰色；这是阅读路径，不是额外模块。
- 2026 的 1/16 默认折叠；冠军的首轮比赛在展开区高亮。
