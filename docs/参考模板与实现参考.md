# 参考模板与实现参考

> **定位**：这里放的是**某些可以参考实现的模板**，不是设计规格，也不是必须照抄的清单。
> 后续实现（首页、索引、详情、后台、图表、空态）都可以从这里找灵感，但**不要局限于这些**。
> 借鉴时优先借“信息组织 / 版式节奏 / 组件形态”，不要整站套模板：
> - 本项目是 Yii2 + Bootstrap 3 + 自建 theme.css / art-r6 夜场层，很多模板的 Bootstrap 4/5、Tailwind、React 代码不能直接用。
> - 引入任何模板代码前先看 LICENSE；GPL/署名条款要与课程交付方式相容，MIT 也要保留版权声明。
> - 模板里的文案、图片、队徽、国旗不要直接搬；数据必须来自本项目的数据源。

**适配本项目的候选（按推荐度）**
1. 场均进球点线（已做首页「1990 触底，2026 反弹」）：11 点、均值线、2–3 个极值注释；不回归、不平滑、不填面积。
2. 十一届冠军条带（下一轮）：年份 + 国旗 + 国名 + 决赛比分，按洲着色；别只放旗、别用 11 种颜色。
3. 进球时间热力图（下一轮）：11 届 × 7–8 个时段，用“该届占比”而非原始球数；先把「进球越来越晚」验证出来再定标题。

## 单位图 / 逐年换位（2026-11-25 调研）

> 为统计页的「四十年射手榜」找参照。只借数据模型与可读性做法，不拷代码、不拷视觉。

| 作品 | 链接 | 可借鉴 |
|---|---|---|
| Observable: Bar Chart Race, Explained（Mike Bostock） | <https://observablehq.com/@d3/bar-chart-race-explained> | 一行一个对象、一列一届；每届重新排名；只显示前 N；标签、旗、值随行移动 |
| Flourish: Bar Chart Race | <https://flourish.studio/visualisations/bar-chart-race/> | 逐年累计的数据准备（一行一个对象、一列一届）、年份计数器、播放 / 拖动；榜单不要超过一屏 |
| The Pudding: Who’s in Your Wallet? | <https://pudding.cool/2022/04/banknotes/> | 一个图形 = 一个人；单位图靠分组和大字号保持可数，不把单位缩成噪点 |
| DataViz Catalogue: Dot Plots & Unit Charts | <http://datavizcatalogue.com/blog/chart-snapshot-dot-plots-unit-charts/> | 单位图的适用条件：单位数有限、每个单位可辨认；颜色只承担一种分类 |
| Reuters: Messi and Mbappé in race for all-time World Cup goal scorers | <https://www.reuters.com/graphics/SOCCER-WORLDCUP/xmvjxkoqzvr/media-embed.html> | 只追领先者、标题直接说竞争；累计值随时间变化，标签跟随而不是全量标注 |

**本站采用（2026-11-25）**：数据模型按「球员 × 届」累计（Flourish / Observable 的做法），画面用「一个点 = 一个进球」的单位图（The Pudding 的做法），但输出是原生 HTML 列表 + CSS 过渡，不引入 D3 或图表库。桌面前十、窄屏前八；金色只标当前届进球，第一名不再重复上金；所有球员不再同时出现在画面里。

## 不局限于模板：可直接对照的“顶级实现”

- **世界杯官方 / FIFA 赛程与晋级图**：两侧向中间收拢的 bracket、轮次标签、冠军路径——本项目晋级图已按这个语言重做。
- **Our World in Data / The Guardian / NYT 体育数据交互**：长周期趋势图的标题写法（先问一个问题）、注释点、口径说明、数据表可展开。
- **ESPN / FotMob / Sofascore / BBC 的筛选工具条**：搜索在前、筛选项内联；条件多时才用弹层；已选条件用 chip / 摘要，结果紧接在下方。本站 2026-11-25 把比赛 / 球队 / 球员统一为同一条 `pl-search` 工具条（3–4 个条件内联，不搬弹层）。
- **ESPN / BBC / FotMob 的比赛页比分板**：点球大战结果直接写在比分线里（`3–3 (4–2 pens)` / `阿根廷点球 4–2 胜`），不加独立模块；本站 2026-11-25 采用同一写法。
- **Football-data / FBref / Sofascore**：比赛页的比分牌、事实行、时间线；表格的数字右对齐与 tabular-nums。
- **B 站 / 视频站的简繁与显示偏好开关**：两段式控件 + cookie 记住选择，点击就地换字、不刷新、不改滚动位置；不是每次切换都重新请求整页。本站 2026-11-25 的球员「中文名 / 原名」按这个做法重做（`name-lang.js`），并把图表/时间线的姓名一起换掉。
- **体育站主导航的滑动下划线**：共享元素 / FLIP 的思路——下划线是独立元素，切页时从上一项滑到当前项，而不是每页各自画一条静态线。本站 2026-11-25 用 `sessionStorage` 记录上一项，在新页先落到旧项再滑到当前项（`nav-underline.js`）；桌面悬停也会预览。
- **Wikipedia 世界杯条目**：每届的赛果、射手、参赛队结构，是核对数据和“信息是否齐全”的基准。
- **Wikipedia 2026 淘汰赛 / NCAA March Madness**：32 队拆成四个 1/4 区，每区 4 场 1/16 → 2 场 1/8 → 1 场 1/4；Final Four 单独成块，四区的胜者两两进半决赛。2026 届次采用此结构（见总纲 §14.2 修订）；1986–2022 仍是两侧 16 强树。
