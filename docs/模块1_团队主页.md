# 模块①：团队主页

> 负责人：李佳婕 2413745（GitHub `vvvvvvprog`）
> 范围：团队展示、成员展示、后台团队信息编辑、作业上传与下载。
> 全站布局、首页和 `theme.css` 由队长维护，不属于本模块。

## 前台入口

| 功能 | 路由 |
|---|---|
| 团队及个人展示 | `index.php?r=team-info/index` |
| 团队/个人作业下载 | `index.php?r=team-info/downloads` |
| 文件下载 | `index.php?r=team-info/download&id=<work.id>` |

团队页读取 `team_info` 和 `member` 表。下载页按 `work.type` 分为“团队”和“个人”，文件本体位于：

- `data/team/`
- `data/personal/`

数据库只保存文件相对路径，下载请求由控制器解析真实路径；绝对路径和 `../` 会被拒绝。

## 后台入口

| 功能 | 路由 |
|---|---|
| 团队介绍 | `index.php?r=team-info/index` |
| 成员管理 | `index.php?r=member/index` |
| 作业管理 | `index.php?r=work/index` |

后台仅允许 `user.role >= 1` 的管理员访问。支持：

- 编辑团队名称、口号、简介和 Logo
- 新增、编辑、删除成员及成员照片
- 上传、替换、删除团队/个人作业文件
- 搜索成员和作业

图片保存到 `frontend/web/uploads/team/`；作业文件保存到 `data/team/` 或 `data/personal/`。删除记录时会同步清理由本模块管理的文件。

## 数据文件

团队成员正式分工由可重复执行的
[`data/module1_team_data.sql`](../data/module1_team_data.sql) 同步：

```powershell
mysql -u root -p worldcup < data/module1_team_data.sql
```
