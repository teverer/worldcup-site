## 风险与替换

- **1986 / 1990**：Commons / 意大利维基标 Public domain，但图源分别含 El Gráfico、AFP/Getty。公开仓库使用前建议再确认；如担心，1986 可换阿兹特克球场（CC BY-SA 3.0），1990 可换德国—南斯拉夫比赛图（CC BY 3.0）。
- **1994 / 1998 / 2002**：Commons 没有可用的当届球场内球员照；现用 Guardian 文章中的编辑图片（Getty / AP），仅作课程展示，公开仓库发布前应复核授权或替换。1994 是 Guardian 的 Baggio + Romário 双联合成，不是单张原图。
- **2006**：CC BY 2.0，需署名；原图已裁到决赛场上的齐达内 / 图拉姆 / 意大利球员，底部摄影师已裁掉。
- 原始候选与审查表在 `runtime/qa/assets/editions3/`（gitignored），站内只提交处理后的 WebP。

## 技术处理

- hero：`frontend/web/images/editions/{year}.webp`，1920×800，质量 84；缩略图 320×180，质量 82。
- 届次页 hero 用真实 `<img>` + `object-fit: cover`，`object-position` 由 `EditionImage` 的 `focus` 控制；hero 媒体层 100vw 出血，文字仍按容器左轴对齐。
- 缺图时 `forYear()` 返回 `null`，届次页不加 `.td-hero-media`，保持原极光头；首页不显示缩略图。
- 首页缩略图可整体回滚：`frontend/views/site/index.php` 的 `$showBoardThumbs = false;`。
- 图片 URL 现在带 `?v=filemtime`，换图后浏览器不会继续用旧缓存。
